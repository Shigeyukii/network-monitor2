機能一覧
ネットワーク監視に必要な機能を一通り

追加のデータベースや専用エージェント不要。Python 環境があればすぐに動きます。

📡

Ping 死活監視

定期的に Ping を送信し UP / DOWN をリアルタイム表示。間隔はデバイスごとに設定可能（デフォルト 60 秒）。

🔌

TCP ポート監視

HTTP (80)・SSH (22) など任意のポートへ TCP 接続チェック。デバイスに複数ポートを登録できます。

📊

SNMP トラフィック監視

v1 / v2c 対応。インターフェースごとの送受信 bps をグラフ表示。64bit カウンターも自動判別。

📨

SNMP トラップ受信

機器側からのプッシュ通知（linkDown・coldStart など）を受信・保存。変数バインド一覧も確認可能。

🔔

アラート通知

UP→DOWN / DOWN→UP の遷移時のみアラート生成。Microsoft Teams・Slack への Webhook 通知に対応。

🌌

星座風ネットワークマップ

デバイスを星に見立てて夜空に配置。トラフィックが多いほど輝き、接続線が流れるアニメーションで表示。

🗂

デバイスグループ管理

拠点・役割別にグループを作成してデバイスを色分け管理。ダッシュボードのタブでフィルター表示。

📋

稼働率レポート

1 時間・24 時間・7 日・30 日の稼働率を一覧表示。CSV ダウンロードで Excel にも展開できます。

🔧

メンテナンスモード

計画停止中のデバイスをワンクリックで監視除外。誤アラートを防ぎ、復旧後は自動で監視を再開。

💾

設定バックアップ・復元

デバイス・グループ・ポート設定を JSON でエクスポート。バージョンアップや別端末への移行が簡単。

セットアップ
5 分で動かす

Python 3.10 以上が動く Ubuntu / Debian / Windows 環境であれば動作します。

1

リポジトリを取得

git clone するか、ZIP でダウンロードして展開します。

git clone https://github.com/Shigeyukii/network-monitor2.git
cd network-monitor2
2

pip をインストール（未導入の場合）

Ubuntu 24.04 以降は pip が同梱されていないため、先にインストールします。

curl -sS https://bootstrap.pypa.io/get-pip.py | python3 - --break-system-packages
3

依存パッケージをインストール

python3 -m pip install -r requirements.txt --break-system-packages
4

起動

cd backend
python3 main.py

起動後、ブラウザで http://localhost:8000 を開きます。
別端末からアクセスする場合は http://<サーバーの IP>:8000 です。

使い方
よく使う操作

📡 デバイスを登録する

  1. 右上の「＋ デバイス追加」をクリック
  2. デバイス名・IP アドレスを入力
  3. SNMP 対応機器の場合は「SNMP を有効にする」をオン
  4. コミュニティ文字列・ポート・バージョンを入力して「追加」
💡 グループを事前に作成しておくと、登録時に分類できます

🌌 マップに配置する

  1. ダッシュボードの「🌌 マップ」タブをクリック
  2. 右パネルの「追加」ボタンで星をマップに配置
  3. 星をドラッグして位置を調整（自動保存）
  4. 「🔗 接続を追加」で 2 つの星をクリックして接続
💡 トラフィックデータがあると星が金色に輝きます

🔔 通知を設定する

  1. 「⚙ 設定」→「通知設定」を開く
  2. Teams または Slack の Webhook URL を貼り付け
  3. 「テスト送信」で疎通確認
  4. 「保存して適用」で有効化
💡 DOWN 検知時・復旧時をそれぞれ ON/OFF できます

🔧 メンテナンスモード

  1. デバイスカードをクリックして詳細を開く
  2. 「🔧 メンテナンス」ボタンをクリック
  3. 監視・アラートがスキップされる
  4. 作業完了後「✅ 監視を再開」で元に戻す
💡 計画停止中の誤アラートを防止できます

💾 設定をバックアップ

  1. 「⚙ 設定」→「デバイス設定のバックアップ・復元」
  2. 「⬇ JSON をダウンロード」でファイルを保存
  3. 新環境では「⬆ JSON を読み込む」で復元
💡 IP が重複するデバイスはスキップされるため二重登録なし

📨 SNMPトラップを受信する

  1. 「⚙ 設定」→「SNMP トラップ受信」を開く
  2. 「トラップ受信を有効にする」をオン
  3. ポート番号を設定（デフォルト: 1620）
  4. 機器側の送信先ポートを合わせて「保存して適用」
💡 標準の 162 番を使う場合は root 権限が必要です
